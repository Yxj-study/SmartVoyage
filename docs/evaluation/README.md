# SmartVoyage 评测证据

## 结论

2026-09-06 对冻结的 160 条 test 样本执行了一次正式离线评测。评测器运行真实 LangGraph Coordinator、Planner 后处理、Supervisor、Worker、Policy、Human-in-the-loop 和长期记忆节点；LLM、A2A、MCP 及外部 API/SQL 返回由确定性 Fixture 替代。

因此，本报告可以证明固定输入下的编排、策略、确认分支和记忆逻辑，不能宣称为真实 LLM 意图识别准确率、线上工具成功率或生产性能。

## 误差分析

5 条任务集合不匹配均是景点偏好边界样本：`test-memory-007`、`019`、`027`、`037`、`045`。样本已保存 `preferred_attraction_types`，但后续问题只说“按我的习惯继续安排”，没有明确提出景点任务。当前策略遵循“当前请求 > 长期偏好”，长期偏好可填充任务参数，但不擅自新增任务，因此未调度 attraction。

这 5 条保留在分母中。后续应先确定产品语义：若要求偏好自动触发任务，需要新的需求评审和新版数据集；不能在本版 test 上直接改标签。
